06 — Aksesibilitas (A11y)

Design System

Standar Aksesibilitas (WCAG 2.1)

Pedoman inklusivitas untuk memastikan tur virtual dapat dinikmati semua kalangan.

Aa

Kontras Warna Teks (Color Contrast)

Rasio kontras teks utama (Seashell #FCF4EA) terhadap background gelap (#0A0D0A) adalah 15.1:1, melampaui standar WCAG AA (4.5:1). Teks sangat jelas terbaca oleh penderita low-vision.

Tab

Navigasi Keyboard

Sistem mendukung navigasi Tab untuk berpindah antar tombol/hotspot, Enter untuk eksekusi, dan tombol Panah untuk merotasi pandangan 360 tanpa mouse.

🔊

Screen Reader Support (ARIA)

Dilengkapi atribut aria-label dan alt tag pada elemen interaktif untuk memberikan konteks deskriptif kepada pembaca layar.

17 — Struktur Data (JSON Schema)

System Design

Skema Data (tourData.ts)

Arsitektur data statis TypeScript yang menggerakkan sistem 360 tanpa database server.

// lib/tourData.ts
export interface HeritageSite {
  id: string;          // "fort-willem-i"
  title: string;       // "Benteng Fort Willem I"
  category: string;    // "Benteng"
  location: string;    // "Ambarawa, Jawa Tengah"
  thumbnail: string;
  rooms: RoomData[];
}

export interface Hotspot {
  pitch: number;
  yaw: number;
  type: 'info' | 'scene';
  text: string;
  targetScene?: string;
}

export interface RoomData {
  id: string;
  title: {
    id: string;      // "Barak Prajurit KNIL"
    en: string;      // "KNIL Soldiers Barracks"
  };
  panorama: string;  // "/gambar/barak-sekarang.jpg"
  hotspots: Hotspot[];
  history: {
    text_id: string;
    text_en: string;
    image_arsip?: string;
  };
}
18 — Tech Stack Overview

Development

Teknologi yang Digunakan

Gambaran lengkap tumpukan teknologi yang membentuk arsitektur sistem.

Frontend Framework

Next.js 14 + React

App Router, TypeScript, SPA behavior untuk transisi ruangan tanpa reload.

Styling

Tailwind CSS

Utility-first CSS. Custom theme tokens untuk warna sejarah. Responsive breakpoints.

Animasi

Framer Motion

Animasi deklaratif untuk Splash Screen, transisi modal, dan efek parallax.

360° Engine

Pannellum (WebGL)

Panorama viewer ringan. Multi-scene tour, hotspots, DeviceOrientation gyro.

Peta Interaktif

Leaflet.js + GMaps

Rendering peta dan kalkulasi jarak dari lokasi pengguna.

Data Storage

Static JSON

In-memory database per ruangan. Zero-latency tanpa server backend.

Hosting

Vercel (Serverless)

CDN global, auto-deploy dari Git. HTTPS otomatis untuk Gyroscope API.

Version Control

Git + GitHub

Branch strategy: main (production), dev (development). Commit atomic.
